# 📊 Project Management Dashboard

A clean and interactive **Project Management Dashboard** designed to track tasks, progress, and workload distribution across different projects and team members.

---

## 🧩 Overview

This dashboard provides a complete snapshot of project activity, helping managers and teams to:

- Monitor total, pending, and completed tasks
- Track average progress across projects
- Analyze workload distribution among team members
- Compare task counts across departments

---

## 📌 Key Metrics

- **Total Tasks:** 46  
- **Pending Tasks:** 37  
- **Completed Tasks:** 9

## 📈 Dashboard Features

### 🔹 KPI Cards
- Total Tasks
- Pending Tasks
- Completed Tasks
- Average Progress

### 🔹 Visual Analytics
- **Bar Chart:** Total tasks by project  
- **Donut Chart:** Tasks assigned to team members  
- **Bar Chart:** Average progress per project  

### 🔹 Filters
- Project Name slicer for dynamic analysis
